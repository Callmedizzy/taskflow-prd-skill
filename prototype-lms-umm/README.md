# Prototype Konsep LMS UMM — Worksheet 12

Prototype klik untuk alur menemukan tugas semester berjalan, melihat detail, memeriksa course, dan mensimulasikan pengumpulan. Data dan unggah berkas hanya simulasi; tidak terhubung ke server LMS.

## Menjalankan
Buka `index.html` di browser modern. Semua aset lokal, tanpa dependensi eksternal.

## Layar
1. Beranda / Dashboard
2. Tugas Semester Berjalan
3. Detail Tugas
4. Periksa Course dan Pilih Berkas
5. Konfirmasi Pengumpulan
